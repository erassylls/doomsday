# Результаты CQA

После оценки разместите файлы, скачанные в разделе «Сдача результатов»:

- `dev/results.json` — DEV: 60 чатов и 5 звонков.
- `prod/results.json` — 10 контрольных чатов, включая явные ошибки обработки.

Формат: JSON 1.0 из приложения к руководству организаторов. Подробности и проверка перед push находятся в [инструкции](../docs/results-submission.md).

Папки подготовлены без фиктивных оценок. `.gitkeep` сохраняет пустую папку и не является результатом. Исходные транскрипты, подписанные URL и ключи не добавляются.
